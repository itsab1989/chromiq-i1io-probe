# Screenshots

What the probe looks like on screen, for instructions and forum posts.

`v1.5.3/` shows the released 1.5.3 exactly as published, taken on
2026-11-13:

- Windows (`01` to `06`, `05b`): a Windows 11 test PC (on ARM, German), the
  tool started from the neutral folder `C:\ChromIQ-probe`, nothing plugged
  in. Pictures `03` and `05` were made with the hidden `--selftest` switch
  (see `tools/vm_test/README.md`): `03` because on Windows on ARM the
  USBPcap offer is normally not shown, `05` because it pretends USBPcap is
  installed. `05b` is Windows' own permission window (in German).
- macOS (`mac-01` to `mac-03`): Terminal on a Mac with SIP on, nothing
  plugged in. The title bar text and the folder paths were removed from
  these copies.

No real instrument and no real recording are shown in any of them.
